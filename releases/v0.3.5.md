# v0.3.5

“我的课程”取消固定分页，课程卡片按窗口宽度和浏览器缩放自动排布，全部可见课程在同一个页面显示。搜索仍遵循班级权限；课程列表里的归档课程隐藏，教师可在管理页维护。

学习天数改为第一次提交至今天的自然天数，按北京时间计算，首次提交当天算第 1 天，没有提交则为 0 天。V008 保存最早提交时间；历史迁移站点可把归档提交的更早时间一并写入，以后整理题库时不会丢失学习起点。课程完成进度仍仅统计已加入课程中的不同题目。

本次配套课程安排：

- 原前三个竞赛团队的正式章节连续编号 1—26：第二个团队从第九章开始，第三个团队从第十七章开始。校内课程保留各自系列的章节编号。
- 七个“未分章节题目”附加题集暂时归档并隐藏，题目和历史提交保留。
- 现有 17 个非校内班级统一开放第一章到第二十一章“二分搜索与二分答案”。16 个校内班级的课程安排保留。学生同时属于两类班级时，看到两边已开放课程的合集。

课程安排是独立的私有数据更新，不写进公开镜像或通过硬编码班级名称限制以后新建的班级。新服务器仍需恢复自己的数据与文件备份。

云端验证：69 项 Java 测试、首次姓名缓存与章节测试、完整课程列表及搜索取消回归测试、前端生产构建。

本次服务器上的程序回退入口：

```bash
python3 /root/hoj-cloud-releases/v0.3.5/switch-version.py previous
```

只回退章节编号、附加题集状态及竞赛班课程分配：

```bash
python3 /root/hoj-cloud-releases/v0.3.5/course-policy.py undo
```

两个回退按需要分别选择，均保留学生提交与成绩。升级后的数据库包含兼容的 V008；回退旧程序应使用本次入口的兼容性验证。旧版本原有清单不修改。

只回退本次课程、图标、介绍及成绩数据：

```bash
python3 /root/hoj-data-updates/curriculum-20261105/switch-data.py undo
```

该操作保留后续新增的提交；如果受影响的课程或历史成绩已经被再次修改，会停止并要求先核查。它不改变应用版本。

另行回退应用到 v0.3.3：

```bash
python3 /root/hoj-cloud-releases/v0.3.4/switch-version.py previous
```

应用回退保留当前数据库，数据回退与应用回退应按需要分别选择。迁往另一台服务器时，除应用镜像外，还需要完整的数据及文件备份；本次私有补充包没有重复打包原题目测试文件。

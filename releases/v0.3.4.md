# v0.3.4

课程增加独立的章节序号，列表与详情显示“第一章、第二章……”。章节编号可由教师编辑，不改变课程原有的排序 ID。

用户名和昵称按累计通过的不同题目数统一着色；每道不同题目计 1 成长分，重复通过不重复计分。个人页显示等级说明，名字颜色会每分钟及页面重新获得焦点时更新。目前不包含作业积分奖励。

修复编译错误信息包含四字节 Unicode 字符时无法保存的问题。数据库升级包含 V006 和 V007；既有题目、账号、原提交源代码和成绩保留。

版本的三个应用镜像均以固定摘要记录在 `v0.3.4.json`，云端完成 67 项 Java 测试、前端回归测试及生产构建。历史版本的标签与镜像不覆盖。

本次只更新线上已有课程的章节编号。十个新增本地课程、课程图标和介绍调整、历史提交重新测评结果属于独立的数据迁移，不通过发布应用镜像写入线上数据库。

本次 ECS 的更新前数据库备份、前后版本配置、镜像引用和独立切换工具保存在 `/root/hoj-cloud-releases/v0.3.4/`。该目录包含私人备份和配置，不得发布到 GitHub。

在本次 ECS 恢复旧版：

```bash
python3 /root/hoj-cloud-releases/v0.3.4/switch-version.py previous
```

重新切回 v0.3.4：

```bash
python3 /root/hoj-cloud-releases/v0.3.4/switch-version.py current
```

查看当前版本：

```bash
python3 /root/hoj-cloud-releases/v0.3.4/switch-version.py status
```

版本切换会暂时停止应用，并检查数据库及数据卷仍指向同一份线上数据。回退到 v0.3.3 时保留兼容的 V006/V007 升级与新产生的提交，不执行数据库备份覆盖。旧版本的严格校验要求其原有五个升级记录，因此切换工具会另外验证镜像及已审核的数据库兼容性。完整灾难恢复应单独操作，不要把恢复旧备份作为日常版本回退。
